Run these SQL files in the Supabase SQL editor for your project, in this exact order:

1. schema.sql
2. migration_race_strava_discover.sql
3. migration_activity_portfolio.sql
4. migration_bucket_list_item.sql
5. migration_profile_public_and_approval.sql
6. migration_canonical_races.sql
7. migration_user_bucket_list_goals.sql
8. migration_strava_synced_activities.sql
9. migration_strava_ingest_state.sql   ← **Required for Strava backfill + incremental cursors** (`user_strava_ingest_state`)
10. migration_match_hub.sql
11. migration_runner_profile_identity.sql
12. migration_race_catalog_imports.sql
13. migration_auth_users_sync.sql
14. migration_strava_canonical_dismissals_update.sql
15. migration_public_race_finishers.sql
16. migration_auth_user_update_sync_name.sql (if not already applied — keeps public.users.name in sync on auth updates)
17. migration_backfill_public_users_from_auth.sql (optional one-time repair for legacy signups)
18. migration_strava_rate_limit_meta.sql — Strava 429 kind + suggested retry (`strava_rate_limit_kind`, `strava_rate_limit_until` on `user_strava_ingest_state`)
19. migration_strava_first_backfill_throttle.sql — first-batch click throttle (`first_backfill_last_attempt_at` on `user_strava_ingest_state`)
20. migration_activity_file_source.sql — `activity_source` on `strava_synced_activities` (strava | garmin_file | manual_file)
21. migration_canonical_enrichment_pipeline.sql — enrichment columns on `canonical_races` + `canonical_enrichment_jobs` queue

Optional / follow-on (not every project):
- migration_strava_ingest_v2.sql — `manual_link_only` on synced activities and race snapshots (run after base Strava migrations if you use that flow)

After running, the public schema must include at least:
- users, races, activities (optional legacy), activity_race_links (optional)
- strava_synced_activities, strava_canonical_match_dismissals, strava_profile_dismissals
- **user_strava_ingest_state** (backfill `before` cursor, incremental high-water, rate-limit hints)
- canonical_races, canonical_race_sources, user_bucket_list_goals
- race_catalog_imports (optional)

If you see PostgREST errors like "Could not find the table 'public.races' in the schema cache",
the base schema.sql (step 1) has not been applied to this Supabase project.

**What breaks without `user_strava_ingest_state`:** historical backfill and incremental Strava sync refuse to run (clear error), since cursors cannot be saved—you would re-fetch overlapping history and risk duplicative work and rate limits. The app detects a missing table and surfaces `supabase/migration_strava_ingest_state.sql` in the UI message.
